# ResuMake

Учебный веб-сервис для создания резюме и портфолио. Текущая версия — стартовый каркас (этап 1), а не завершённое приложение.

## Текущий стек

- Python 3.12 (рекомендуемая версия)
- Flask, Flask-SQLAlchemy, Flask-Migrate
- Flask-Login, Flask-Bcrypt
- SQLite для локальной разработки
- Jinja2 + Bootstrap 5
- pytest

## Запуск локально

1. Установите Python 3.12.
2. Создайте и активируйте виртуальное окружение:

   ```bash
   python -m venv .venv
   ```

   macOS/Linux:

   ```bash
   source .venv/bin/activate
   ```

   Windows PowerShell:

   ```powershell
   .venv\Scripts\Activate.ps1
   ```

3. Установите зависимости:

   ```bash
   python -m pip install --upgrade pip
   pip install -r requirements.txt
   ```

4. Скопируйте `.env.example` в `.env` и задайте собственный `SECRET_KEY`.
5. Запустите приложение:

   ```bash
   python run.py
   ```

6. Откройте адрес, который Flask покажет в терминале (обычно `http://127.0.0.1:5000`).

## Тесты

```bash
pytest -q
```

## Миграции БД

После установки и настройки Flask CLI:

```bash
flask --app run.py db init
flask --app run.py db migrate -m "Initial schema"
flask --app run.py db upgrade
```

Для быстрого локального smoke-test модели можно временно создать таблицы через `db.create_all()` в контексте приложения; миграции предпочтительны для нормальной разработки. Не запускайте `db init` повторно, если каталог миграций уже существует.

## Архитектурные решения, которые уже зафиксированы

- `User.role` содержит только `user` или `admin`. Premium-статус определяется активной подпиской, а не отдельной ролью.
- Тарифы в модели подписки: `free`, `premium`, `one`.
- Для JSON-секций резюме и ссылок портфолио используются JSON-колонки SQLAlchemy.
- У пользователя может быть не более одного портфолио.
- Удаление пользователя каскадно удаляет связанные резюме, портфолио и подписки.
- Секреты хранятся в переменных окружения; файл `.env` не коммитится.
- Текущая версия ещё не реализует регистрацию, редактор, PDF, оплату, публикацию и административные маршруты.

## Решения, требующие подтверждения в ходе ревью

1. Тариф One трактуется как один резюме-документ с премиальными возможностями для этого резюме. Нужно уточнить, включает ли он собственный slug и портфолио.
2. Подписка `free` будет представлять базовый доступ; правила срока действия и переходов тарифов будут реализованы отдельным сервисом.
3. В ТЗ цена Premium встречается как 500 и 499 рублей. Для проекта зафиксировано 499 рублей по решению ревьювера.
4. Английская локализация будет добавлена после реализации русскоязычных сценариев.
